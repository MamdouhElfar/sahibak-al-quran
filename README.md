# صاحبك القرآن

كان اسمه «خريطة المصحف».

تطبيق سطح مكتب يرسم لك القرآن الكريم كاملًا — ٦٢٣٦ آية — لترى أين تقف: ما حفظت، وما فهمت، وما يحتاج إلى مراجعة، وما قرأت اليوم.

## ما فيه
- **الخريطة:** السور والصفحات والأجزاء، تمتلئ كل بطاقة بقدر ما أنجزت فيها، مع تحديد عدة سور أو صفحات أو أجزاء مرة واحدة.
- **خطة اليوم:** ورد القراءة، وورد الحفظ الجديد (من موضع حفظك)، وورد المراجعة المحسوب من محفوظك ودورة المراجعة.
- **المصحف:** طبعة المدينة 1441 سطرًا بسطر (خطوط مجمع الملك فهد QPC V2)، صفحتان متقابلتان تُقلَّبان بسحب الفأرة.
- **التفسير:** اضغط على أي آية ليظهر تفسيرها؛ الميسر مضمَّن، والسعدي وابن كثير والطبري والقرطبي والبغوي والوسيط تُنزَّل لكل سورة أو كاملة.
- **المتابعة:** آخر ٣٠ يومًا للقراءة والحفظ والمراجعة، والأيام المتتالية، والختمة الحالية.
- **بياناتك:** على جهازك وحده (`%APPDATA%\Sahibak Al-Quran\data.json`) مع نسخة احتياطية تلقائية لكل يوم.

## التثبيت
نزّل `Sahibak-Al-Quran-Setup-<الإصدار>.exe` من صفحة [Releases](../../releases) وثبّته. يحدّث التطبيق نفسه تلقائيًا عند صدور إصدار جديد.

## التطوير
```
npm install
npm start          # تشغيل التطبيق
npm run smoke      # اختبار الشاشة
npm run dist       # بناء ملف التثبيت في dist/
```
يعمل أيضًا في المتصفح: `npm run web` ثم افتح `http://localhost:8765`.
